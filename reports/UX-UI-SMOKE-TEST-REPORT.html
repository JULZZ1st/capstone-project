Confirmed issue and fix

UX-001 — Donor wizard displayed validation warning on initial open

Severity: Medium · Status: Fixed and verified

The donor creation modal rendered “Please fill out the remaining field” before the user clicked Next or Save. The alert had the hidden attribute, but a Tailwind flex utility overrode the browser hidden rule. This made a validation message look like an error immediately on a blank form.

Fix: added an explicit global [hidden] { display: none !important; } base rule in resources/css/app.css. The browser retest confirmed hidden=true and computed display:none on initial modal open.

Usability observations

  • Sidebar labels are descriptive and consistent across all primary pages.
  • Empty states provide contextual next actions on the dashboard and report areas.
  • Donor creation uses a four-step wizard. This is understandable, but it is a relatively high-click workflow; consider showing a compact progress summary and only requiring steps that contain mandatory fields.
  • Reports expose many report types in one horizontal navigation group. On smaller screens, confirm wrapping/overflow behavior and consider grouping operational reports separately from exports.
  • System Administration correctly exposes Staff rather than the removed Secretary/Treasurer choices.
